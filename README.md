# Study Python 🐍

A repository dedicated to learning Python and building practical test automation frameworks using **Pytest**.

---

## 📂 Project Structure

Here is an overview of the key directories and files in this repository:

* **`pages/`** - Page Object Model (POM) classes representing different web pages or views (e.g., cart overview, chart info, checkout).
* **`tests/`** - Test suite containing automated test cases built using Pytest.
* **`utils/`** - Helper functions, utilities, and reusable modules.
* **`__pycache__/`** - Python compilation cache.
* **`conftest.py`** - Pytest configuration file containing shared fixtures and setup/teardown logic.
* **`pytest.ini`** - Configuration file for customizing Pytest execution and environment settings.
* **`exitExample.py`**, **`first.py`**, **`swardfish.py`**, **`yourName.py`** - Initial Python practice scripts and examples.
